# AuroraBot Docs

AuroraBot は、統一イベント認知、MCP ネイティブ App、追跡可能な認知状態を中心に設計された自律エージェントフレームワークです。

現在のアーキテクチャ再設計期間中は、中国語ドキュメントを正本とします。

- 概要: <https://www.aurorabot.org/start/overview.html>
- システム構成: <https://www.aurorabot.org/architecture/system-overview.html>
- Platform runtime: <https://www.aurorabot.org/architecture/platform-runtime.html>
- App 開発: <https://www.aurorabot.org/develop/app-development.html>
- Brain 再設計草案: <https://www.aurorabot.org/architecture/brain-redesign.html>

日本語版は Platform/App の MCP 化と Brain 再設計が安定した後に拡充します。
