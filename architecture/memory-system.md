# 记忆系统

::: warning
施工中。旧 L1/L2/L3 与 SelfStream 的实现说明暂不作为目标文档维护。
:::

记忆系统的长期目标不是“保存更多聊天记录”，而是维护生命体连续性。

稳定原则：

- 记忆必须服务于当前处境理解，而不是无差别堆积。
- 事件、体验、关系、承诺、偏好、未完成事务应分层保存。
- 可检索记忆与第一人称自我叙事需要分离，但互相引用。
- App 私有数据不等于 Brain 记忆；只有被体验和解释过的信息才进入 Brain。

新的记忆分层方案见：[Brain 架构重设计](./brain-redesign.html#记忆模型)。
