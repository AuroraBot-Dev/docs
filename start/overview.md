# AuroraBot 是什么

AuroraBot 是一个自主智能体框架：它不只是一个等着你发消息的聊天机器人，而是一个可以持续存在、有自己的节律、在环境里自主判断和行动的 Agent。

## 一次运行，一棵树

一次运行就是一棵 AgentTree。模型读取四条来源的消息（系统设定、输入、自己的回话、工具结果），决定下一步：直接回答、调用工具，或者委派一个子 Agent 去干活。委派出去的子 Agent 又长成一棵小树，完成之后把结果带回给父节点。整棵树跑完，一次运行就结束了。

## 所有输入都是世界的变化

用户消息、时间流逝、外部应用事件，在 AuroraBot 眼里都只是"世界发生了什么"。它们全部先写进同一条世界线（WorldJournal），再按需要进入 Agent 的视野。谁在什么时候观察过什么，都有记录可查；模型看到的每一条事实，都有一条对应的因果路径。

## 没有人说话，它也会醒来

节律（cadence）让时间本身成为输入：每隔一段时间提交一次 tick，外部事件到达时按规则唤起一棵树。Agent 醒来后自己判断要不要行动，而不是永远停在输入框后面。

## 它还记事儿

每次模型请求前，只读记忆会把最近时间窗口内的世界活动整理成一段摘要，注入 Agent 的上下文中。超长的上下文会被确定性截断，模型不会因为聊得太久就糊涂。

## 行动之前先声明

模型负责想，不负责直接改变环境。外部行动必须经过已声明的工具、参数校验与执行，结果再作为新事件回到 Agent。自主不等于失控。

## 从命令行跑起来

`aurora start` 会打开一个本地终端：输入普通文本启动一棵树，输入 `/help` 查看操作，输入 `/exit` 退出。完整的安装与配置见 [安装与验证](./getting-started.md)。
