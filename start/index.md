# 开始使用

建议按以下顺序阅读：

1. [认识 AuroraBot](./overview.md)：先确认她是什么、当前能做什么，以及 0.5 alpha 不承诺什么。
2. [快速开始](./getting-started.md)：从 `nightly` 源码完成一次可预测启动。
3. [配置](./configuration.md)：配置模型、Agent、MCP App、存储和进程入口。
4. [运行与操作](./operations.md)：使用 Console、操作命令、日志与健康检查。
5. [Web 管理面板](./panel.md)：连接独立 Panel 前端并理解认证边界。

::: warning Nightly 文档
当前文档对齐 `nightly@97a5bdb`，属于 0.5.0 alpha 开发线。开始前请阅读
[Nightly 实现状态](../reference/nightly-status.md)。
:::
